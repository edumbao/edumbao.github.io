About

Process

How I decide what a page should do.

01

Start with the reader

Define who is searching, what they are trying to accomplish and what is making the task difficult.

02

Check the existing site

Review related pages, search intent, keyword overlap, internal links and whether an older URL should be improved first.

03

Study the product

Check current documentation, screenshots, workflows and supported claims before writing product-focused sections.

04

Build useful structure

Use direct answers, practical examples, workflows and clear sections instead of repeating a keyword around the page.

05

Review the page as part of the system

Check links, CTAs, metadata, visuals, supporting pages and the older content that should point back to the new page.
